# Plan: Nix Flake + NixOS Module for vod2pod-rss

## Structure

```
flake.nix              # Main flake: devShells, packages (x86_64 + aarch64), nixosModule
nix/modules/
  vod2pod-rss.nix      # NixOS service module (services.vod2pod-rss)
nix/yt-dlp-version.nix # Pin yt-dlp version (replaces requirements.txt)
```

---

## 1. `flake.nix` — Top-level flake

### Outputs

| Output | Description |
|---|---|
| `packages.x86_64-linux.package` | cargo build of the app binary |
| `packages.aarch64-linux.package` | cross-compiled cargo build (target `aarch64-unknown-linux-gnu`) |
| `devShells.x86_64-linux.default` | dev shell with: cargo, rust-analyzer, ffmpeg, yt-dlp, redis-cli, cargo-watch |
| `devShells.aarch64-linux.default` | same + cross-compilation toolchain |
| `nixosModules.vod2pod-rss` | imports the module from `nix/modules/` |

### Build details (`buildRustPackage`)

- **Source:** `src/`, `Cargo.toml`, templates, `.cargo/config.toml`
- **`nativeBuildInputs`:** `pkg-config`, `openssl.dev` (vendored feature needs libssl headers)
- **`buildInputs`:** `ffmpeg`, `yt-dlp` (from pinned version), `openssl`, `redis`
- **`cargoLock`:** generated via `cargo generate-lockfile` in the flake (not committed to git — stays `.gitignore`d, only for Nix reproducibility)
- **`OPENSSL_DIR`, `OPENSSL_LIB_DIR`, `OPENSSL_INCLUDE_DIR`:** set by Nix's openssl package for the vendored feature
- **`FFMPEG_DIR`:** set by Nix's ffmpeg package

### Cross-compilation (aarch64)

- Uses `rustPlatform.buildRustPackage` with `target = "aarch64-unknown-linux-gnu"`
- Cross-linker already configured in `.cargo/config.toml` (`aarch64-linux-gnu-gcc`)
- `aarch64-linux-gnu.gcc` added to `nativeBuildInputs`

### Service definition

systemd service that:
- Depends on `redis.service` (provisioned alongside)
- Runs the vod2pod-rss binary with env vars set from options
- Opens `services.vod2pod-rss.port` in the firewall

### Redis provisioning

```nix
services.redis = {
  enable = true;
  settings = {
    save = "20 1";
    loglevel = "warning";
  };
  bind = config.services.vod2pod-rss.redisAddress;
  port = config.services.vod2pod-rss.redisPort;
};
```

## 3. `nix/yt-dlp-version.nix` — Version pinning

```nix
{ version = "2026.06.09"; }  # matches requirements.txt
```

The flake uses `builtins.fetchurl` to get the yt-dlp release binary from GitHub at this exact version, replacing the Dockerfile's runtime download. The `requirements.txt` file can be removed or repurposed as a reference.

---

## 4. Dockerfile changes (optional, non-blocking)

The Dockerfile can be updated to copy the Nix-built binary instead of building in-container, but this is a separate PR. The flake works independently — the Docker build continues to function as-is.

---

## Execution order

1. Create `nix/yt-dlp-version.nix` with the pinned version
2. Create `nix/modules/vod2pod-rss.nix` — full NixOS module
3. Create `flake.nix` — ties everything together (devShells, packages, module export)
4. Validate: `nix flake check` (builds package for both platforms, enters dev shell)
5. Update `AGENTS.md` with new commands (`nix develop`, `nixos-rebuild`)

## Trade-offs & decisions

| Decision | Choice | Rationale |
|---|---|---|
| `Cargo.lock` in git? | No — generated by flake only | Matches existing `.gitignore` convention; Nix needs it for reproducibility |
| yt-dlp source | Prebuilt binary from GitHub releases | Same approach as Dockerfile; avoids Python build complexity in Nix |
| Cross-compilation | Native aarch64 build via `rustPlatform` | Simpler than cross-compile; `.cargo/config.toml` already has linker config |
| Module scope | NixOS only (not home-manager) | This is a server service; home-manager not applicable |
| Redis in module | Yes, provisioned alongside | Self-contained deployment; matches docker-compose dev setup |
| Platforms | x86_64 + aarch64 | Matches Docker multi-arch support and Raspberry Pi use case |
